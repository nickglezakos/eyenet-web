# EyeNet social flashcards — showcase

Netflix-style horizontal strip of **9 laconic flashcards**. Page body is cards only.

## Preview

```bash
cd marketing/flashcards
python -m http.server 8770
# open http://127.0.0.1:8770/
```

## UX

- Horizontal snap-scroll rail on desktop and mobile
- Peek of the next card; arrow buttons on hover / touch
- Each card: logo + motto · 16:9 visual (`object-fit: contain`) · larger sell block
