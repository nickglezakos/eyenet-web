## Objective

1. **Explain** Virtual Ward in one swipe: ordinary camera → EyeNet trigger → action → care team.  
2. **Differentiate** vs vitals-only RPM and “camera wall” surveillance.  
3. **Drive** to value wiki `/why/home-care/` (or invest/contact CTA as needed).

**Primary message:** Hospital-grade safety in every unstaffed home — falls, help-calls, and zone breaches as a few targeted alerts. Vision stays on-prem.

## Split still template (locked)

Every slide (except optional end card) uses the same frame:

```
┌─────────────────────────────┐
│  TOP (~50%)  people / scene │  photoreal, ethical home-care acting
├─────────────────────────────┤  soft 1–2px divider (brand dark / soft grey)
│  BOTTOM (~50%) EyeNet UI    │  real screenshot, cropped for legibility
└─────────────────────────────┘
  + short caption bar OR corner text (platform-safe safe-zone)
```

**Rules**

- Top never shows fake product chrome.  
- Bottom never invents UI — use files from `assets/eyenet-wiki/`.  
- Prefer **one idea per slide**; carousel tells the sequence.  
- Keep faces respectful; no graphic medical moments in stills.  
- Logo: small EyeNet mark bottom-right or end card only (don’t cover UI controls).

## Creative do / don’t

**Do**

- Keep split consistent across the carousel (same divider height)  
- Use real UI crops that remain readable at phone size (zoom UI 110–130% if needed)  
- Match top emotion to bottom screen (arrival ↔ detect; help ↔ trigger/action)  
- Offer a single-image “hero” (slide 05b or 06) for LinkedIn boosts  

**Don’t**

- Fake dashboards or stock “AI brain” graphics on the bottom  
- Graphic falls, distress porn, or continuous surveillance framing  
- Imply clinical video is stored or streamed to the cloud  
- Overload slides with paragraphs of on-image text
