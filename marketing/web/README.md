# EyeNet marketing microsites

Static marketing hub + seven use-case microsites. Each microsite mirrors the section grammar of [eyenet-vision.com](https://eyenet-vision.com/) (hero, capability cards, quotes, In Action strip, roles, application focus, modes, deep dive, CTA). Copy is remapped from the value wiki’s Most Valuable Cases.

## Serve locally

```bash
cd marketing/web
python3 -m http.server 8770
```

Open http://127.0.0.1:8770/

## Rebuild pages

Case microsite HTML is generated by `scripts/build_microsites.py`. The hub `index.html` is hand-maintained (chapter UX) and is **not** overwritten by the builder.

```bash
python3 scripts/build_microsites.py
```

## Integration with eyenet-vision.com

When the repo root is published as the product site:

| From | To |
|------|----|
| Product sticky FAB / section CTAs | `/marketing/web/` and each case folder |
| Product `#primary-use-cases` strip | Seven microsite entries |
| Marketing sticky FAB / close CTAs | `https://eyenet-vision.com/` and `#primary-use-cases` |
| Value deep-links | `https://value.eyenet-vision.com/why/{slug}/` |
