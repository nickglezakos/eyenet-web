Περίπτωση EyeNet 01: Ξέρετε ποιός είναι παρόν και ποιος όχι · Πλησιέστερος ανταγωνιστής: Verkada

Η ιστορία του ανταγωνιστή

Ομάδες workplace security & facilities που αγοράζουν cloud κάμερες με people analytics.

Η Verkada πουλάει ολοκληρωμένη cloud πλατφόρμα φυσικής ασφάλειας — κάμερες, access, αισθητήρες και People Analytics / occupancy — σε επιχειρήσεις που θέλουν dashboards χωρίς να διαχειρίζονται VMS. Είναι ισχυρή στην παρουσία χώρου εργασίας όταν ο αγοραστής δέχεται hardware Verkada και cloud control plane. Δεν τοποθετείται ως any-camera, on-prem Detect → Decide → Act για ναυτιλία, home care, πόλη και τις υπόλοιπες περιπτώσεις EyeNet.

Πού σταματούν: Cloud + ιδιόκτητο device estate· analytics παρουσίας για workplaces — όχι sovereign multi-vertical action fabric.
